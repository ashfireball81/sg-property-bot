## 📝 Step-by-Step Deployment

### Step 1: Prerequisites

```bash
# Verify you have everything
flyctl version          # Should show version
flyctl auth whoami      # Should show your account
```

If not installed:
- Download: https://fly.io/docs/getting-started/installing-flyctl/

### Step 2: Deploy Infrastructure

**Windows (PowerShell):**
```powershell
cd C:\Users\ash_f\Desktop\python\sg-property-bot
.\scripts\deploy.ps1
```

**macOS/Linux (Bash):**
```bash
cd ~/Desktop/python/sg-property-bot
chmod +x scripts/deploy.sh
./scripts/deploy.sh
```

### Step 3: Save Connection Strings

After deployment, you'll see output like:
```
API URL: https://sg-property-bot.fly.dev
Database: postgresql://user:pass@sg-property-db.internal:5432/...
Redis: redis://sg-property-cache.internal:6379
```

**Save these to `.env` file**

### Step 4: Deploy Database Schema

```bash
flyctl postgres exec sg-property-db < database/schema.sql
```

### Step 5: Verify Deployment

```bash
# Test API
curl https://sg-property-bot.fly.dev/health

# Check logs
flyctl logs --app sg-property-bot

# Monitor
flyctl status --app sg-property-bot
```

## 🚨 Common Issues & Solutions

### "Authentication failed"
**Solution:**
```bash
flyctl auth logout
flyctl auth login
# Follow browser login flow
```

### "Database connection refused"
**Solution:**
```bash
# Check database is running
flyctl status -a sg-property-db

# Restart if needed
flyctl restart -a sg-property-db

# Wait 30 seconds, retry
```

### "API returning 502 Bad Gateway"
**Solution:**
```bash
# Check API logs
flyctl logs -a sg-property-bot

# Restart app
flyctl restart -a sg-property-bot

# Check environment variables
flyctl config show -a sg-property-bot
```

### "Out of memory" errors
**Solution:**
```bash
# Upgrade resources
flyctl postgres update sg-property-db --vm-size performance-1x
```

## 💾 Backup Strategy

### Automatic Backups
Fly.io PostgreSQL has automatic daily backups (30-day retention).

### Manual Backup
```bash
# Export database
pg_dump $DATABASE_URL > backup-$(date +%Y%m%d).sql

# Restore database
psql $DATABASE_URL < backup-20261004.sql
```
